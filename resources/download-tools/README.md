# Observation file tools bundled with MARK

MARK uses the bundled tools to decompress observation downloads and restore Hatanaka-compressed files to RINEX. Keep the executables, library and their accompanying license documents together in this directory.

## CRX2RNX 4.2.0

The original GSI Windows x64 binary `CRX2RNX.exe` is included unchanged.

- [Official release page](https://terras.gsi.go.jp/ja/crx2rnx.html)
- Original terms: `RNXCMP-LICENSE.txt`
- Original package documentation: `RNXCMP-README.txt`

Reference required for combined software distribution:

Hatanaka, Y. (2008), *A Compression Format and Tools for GNSS Observation Data*, Bulletin of the Geographical Survey Institute, 55, 21–30. [Publication](https://www.gsi.go.jp/ENGLISH/Bulletin55.html).
