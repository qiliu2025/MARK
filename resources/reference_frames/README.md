# IGS reference-frame station lists

These files contain the public IGS core-network lists used by MARK's IGS/ITRF reference-frame quick plans. Each line lists the four-character code of a primary station and its permitted substitutes.

Keep all five `*_core.txt` files together. MARK selects the applicable reference frame from the query date and uses the matching station list.

Validity dates follow the IGS Reference Frame Working Group chronology:

- IGS14: 2017-01-29 through 2020-05-16
- IGb14: 2020-05-17 through 2022-11-26
- IGS20: 2022-11-27 through 2025-02-01
- IGb20: 2025-02-02 through 2026-01-10
- IGc20: 2026-01-11 onward
