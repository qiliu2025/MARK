# Offline map data

MARK includes an offline reference map for viewing station positions and selecting spatial ranges.

Natural Earth supplies the map geometry, geographic labels and coordinate lookup data. The data are in the public domain. The bundled files use selected attributes and converted geometries.

- Data and terms: https://www.naturalearthdata.com/about/terms-of-use/.
- Source repository: https://github.com/nvkelso/natural-earth-vector.
- Bundled notice: `map-sources/natural-earth-public-domain-README-20260929.txt`.

Station metadata supplies country and region values. Coordinate lookup is a fallback when the selected Site Log country field is unavailable.
